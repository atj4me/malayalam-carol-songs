# Malayalam Carol Songs — Lyrics

A simple phone-friendly page to select and read Malayalam Christmas carol song lyrics.

- Tap a song from the numbered list, or search in English or Malayalam
- Big Malayalam lyrics with A− / A+ text resizing
- Previous / Next navigation
- "Original scan" on each song shows the source page it was transcribed from

Lyrics transcribed from the Carol 2024 song book and additional song sheets shared by the carol group. Songs 11–12 in the book are handwritten and transcribed best-effort — check the original scan if a word is unclear.
